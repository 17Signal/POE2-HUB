# PoE2 HUB

PoE2 HUB 是一个《流放之路 2》常用入口聚合页，用来集中整理我自己常看的官方页面、构筑工具、资料站和社区论坛。

在线地址：

- GitHub Pages: https://17signal.github.io/POE2-HUB/

## 收录内容

当前页面按用途整理了这些链接分类：

### 官方入口

- Path of Exile 官方网站
- Official Forums
- Official Trade

### 构筑工具

- PoE2 Ninja Builds
- PoE2 Ren Builds
- Caimogu Planner

### 社区论坛

- Gamer TW Forum
- NGA Forum
- Caimogu Circle

### 数据资料

- PoE2DB

## 技术栈

- Vite
- React
- TypeScript
- Tailwind CSS

## 说明

这是一个纯静态页面项目，当前版本不包含站点新增、编辑、删除等后台管理功能，只用于展示和跳转常用链接。
